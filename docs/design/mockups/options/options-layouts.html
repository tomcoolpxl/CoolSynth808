CoolSynth 808: Options in pages

The Options window today is 600 by 1120 points, five sections in one column. Each layout below splits it into pages and tightens each page: the MIDI inputs a tick list instead of a key each, the window size a list to pick from, the drum notes a compact grid. Each window is drawn at its real size. Ableton (Settings, a tab per page down the left) and Bitwig (Dashboard, Settings pages) split theirs the same way.
